How it works

Finding things. Every item carries a caption node holding its name, tags and notes. In Ctrl+F only mode that caption is rendered at zero opacity — invisible, but the browser's own Ctrl+F still matches it, scrolls to it and highlights the tile. The in-app search box (/) additionally dims non-matches and can select every hit at once.

Search syntax. Space-separated terms are ANDed. tag:starter, tier:A, note:vuln, -word to exclude, "two words" for a phrase.

Keys. / or Ctrl+F search · Enter while searching selects all matches · Esc clear · Ctrl+A select matches · Del delete selection · Ctrl+S save board · Ctrl+Z undo · double-click a tile to open the inspector.

Navigating while dragging. Keep holding an item with the left mouse button, then use the wheel to zoom or hold the middle mouse button and move to pan. The item remains attached to the pointer and drops normally when you release the left button. Press Esc to cancel the move.

Comparison markers. Ranked/unranked changes use R or U, and tier changes use vertical arrows. Within one tier, horizontal arrows count only shared items that the card actually crossed; board-specific cards do not create false movement. A ↔ marker means the card moved ahead of some shared items and behind others.

Syncing sub-boards. Hold Ctrl while dropping an item to move the selection into that tier on every sub-board. A matching insertion point is preserved where possible; otherwise the selection is appended. Ctrl-dropping into the unranked pool moves it into the pool on every sub-board.

Importing. TierMaker builds its item carousel in JavaScript and blocks server-side readers, so a browser on its own can't reliably scrape it. Run TierForge.cmd (or npm run serve) and open the page it hands you—the URL box then imports directly. Without the runtime, use the bookmarklet on the Grab from page tab: it runs inside your own TierMaker tab, where there is no CORS and no challenge. Public proxies are tried too, but they often come back empty.

Remix links and going back. A ?ref=list-remix link holds no list id — TierMaker's clone button keeps the arrangement in your browser's storage — so only the bookmarklet can pick it up, and it does, along with anything you have dragged on that page. Export → Back to TierMaker reverses the trip: it rebuilds TierMaker's own list code from your board and hands you a bookmarklet that opens it there.
